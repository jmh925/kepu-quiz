### 1.3 技术主线（全文唯一口径）

论文全篇只使用下面这一套技术栈，第 2 章介绍、第 4 章设计、第 5 章实现必须首尾一致：

| 层次 | 实际选型 | 说明 |
| --- | --- | --- |
| 前端 | 微信小程序（页面规划：闯关首页 / 答题闯关 / 复盘报告 / 个人中心 / 知识库）＋ 网页版学生端 `/app/`（零构建原生单页应用） | 均已实现，见第六节与 8.3 |
| 后端 | Python 3.13 + FastAPI + Uvicorn + Pydantic v2 | 已实现并跑通 |
| 大模型 | DeepSeek（OpenAI 兼容 `/chat/completions` 接口，httpx 调用，deepseek-chat） | 已实现，Key 为空时自动降级 |
| 降级题库 | 内置科普题库 **150 题** / 6 大主题（天文、地理、生物、物理、化学、科技），每主题 25 题，关键词主题匹配 | 已实现，数据文件见 8.3 |
| 检索增强 | 轻量 RAG：文档解析 → 段落+长度分块（约 300 字）→ 中文 2-gram 词频向量 → 余弦相似度 → Top-3 片段注入 Prompt | 已实现 |
| 数据库 | SQLite（**10 张表**，原生 SQL + 连接复用与线程锁），可平滑迁移 MySQL | 已实现 |
| 鉴权 | PyJWT 签发 HS256 Token（有效期 7 天）＋ 登录名口令注册登录 / 游客体验 / 游客数据合并 | 已实现（微信服务端校验为预留，见第六节） |
| 错题本 | 答错自动入库并累加错误次数，答对即视为已掌握并移除；支持「只练错题」（不调用大模型，毫秒级返回） | 已实现 |
| 学段适配 | 小学低年级 / 小学高年级 / 初中三档，按学段收敛题量、题干长度、用词难度与报告语气 | 已实现 |
| 内容安全 | 用户输入做敏感词与长度校验；模型生成的题目逐题过滤，不合规的丢弃并用内置题库补齐题量 | 已实现 |
| 接口风格 | RESTful，统一前缀 `/api/v1`，统一响应 `{code, message, data}`，共 **33 个接口**（学生端 19 + 管理端 14） | 已实现 |

**全文不再出现**：SpringBoot、Redis、LangChain、LangGraph、ReAct Agent、Tavily 联网搜索、Chroma 向量库、阿里云百炼 Embedding、通义万相文生图、腾讯云 COS 对象存储、MySQL + aiomysql 异步连接池、异步任务轮询架构、Docker / 微信云托管、Locust。
