# 中小学生科普知识闯关小程序设计与实现

## 摘 要

针对中小学生课外科普学习缺少合适练习载体的问题，本文设计并实现了一个按学段分级的科普知识闯关系统。面向小学低年级至初中三个学段，以“说主题—出题—答题—复盘—错题沉淀”为主线，实现了出题、答题判题、复盘、错题本、知识库与个人中心六个基础模块，并扩展了语文、数学、英语题库、同伴对战与段位阶梯。

系统采用前后端分离的分层架构，后端基于Python与FastAPI提供38个接口，用SQLite的11张数据表存储数据，内置题库225道题，覆盖9个主题并按学段分开存放。针对大语言模型输出不稳定的问题，通过调用约束、接收校验与题库补足控制题目质量，并为出题、复盘和错题练习设计了降级方案，使系统在无模型密钥或断网时仍能完成完整流程；学段适配则把题量与题干、选项长度上限落实为可检查参数，并保证低年级与初中不共用题干。

系统编写了可重复执行的验收脚本共17项检查，覆盖接口功能、题库规范、学段分离、错题本增删改查与界面渲染等。测试表明各项功能达到设计要求，不含模型调用的接口响应在300毫秒以内；脚本还发现并修正了错题收录时机、对手数据取值、题库答案与解析不一致、窄屏横向溢出与对比度不足等问题。

**关键词：** 科普知识闯关，微信小程序，学段分级，大语言模型

## ABSTRACT

To address the lack of suitable practice tools for primary and secondary school students in learning science knowledge outside the classroom, this paper designs and implements a grade-banded science knowledge challenge system. The system serves three grade bands: lower primary, upper primary and junior high school. Following the thread of "students name a topic — the system generates questions on the spot — students answer questions — a review report is produced — wrong answers accumulate for later practice", it implements six basic modules: question generation, answering and grading, review reports, a wrong-answer notebook, a knowledge base, and user and personal center. On this basis, three extended functions are designed: question banks for the basic courses of Chinese, mathematics and English, peer competition, and a rank ladder.

The system adopts a layered architecture with separated front and back ends. The back end is built on Python and FastAPI and provides 38 interfaces. Data is stored in SQLite across 11 tables. The built-in question bank contains 225 questions covering 9 themes, stored separately by grade band. To handle the unstable output of large language models, question quality is controlled through three steps: constraining the call, validating the response, and filling gaps from the question bank. Degradation paths are designed for question generation, review reports and wrong-answer practice, so that the system remains fully usable without an API key or a network connection. For grade adaptation, the number of questions and the upper limits on question stem and option length are implemented as checkable parameters, and question stems never overlap between lower primary and junior high school.

A repeatable acceptance script was written, covering 17 checks on interface functions, question bank standards, grade separation, wrong-answer notebook operations, the peer competition flow, and interface rendering and contrast. Test results show that all functions meet the design requirements, and the response time of interfaces that do not call the model is within 300 milliseconds. During development, the checking scripts detected and helped fix several problems, including incorrect timing in recording wrong answers, the wrong column being read for opponent data, inconsistent answers and explanations in the question bank, horizontal overflow on narrow screens, and insufficient text contrast in several places.

**KEY WORDS:** science knowledge challenge, WeChat mini program, grade banding, large language model
