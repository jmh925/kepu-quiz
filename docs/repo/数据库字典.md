## 表 4-1 用户表（`users`）

存储学生账号：openid、登录名、口令哈希与盐、昵称、累计经验值、状态与常用学段

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | 主键 |  | 自增主键 |
| openid | TEXT | 非空 |  | 微信用户标识；未接入时由本地生成，形如 local_xxxx |
| username | TEXT | — |  | 登录名（3~20 位字母、数字或下划线），游客账号为空 |
| password_hash | TEXT | — |  | 口令的 PBKDF2-HMAC-SHA256 哈希（12 万次迭代），游客账号为空 |
| salt | TEXT | — |  | 每账号独立随机盐 |
| nickname | TEXT | 非空 | '学习者' | 昵称 |
| avatar_url | TEXT | 非空 | '' | 头像地址（当前为空字符串） |
| total_xp | INTEGER | 非空 | 0 | 累计经验值 |
| status | INTEGER | 非空 | 1 | 1 正常 / 0 停用（管理端可操作；游客数据合并后停用） |
| grade | TEXT | 非空 | 'primary_high' | 学段：primary_low / primary_high / junior |
| last_login_at | TEXT | — |  | 最近登录时间 |
| created_at | TEXT | 非空 | datetime('now','localtime') | 创建时间（本地时区） |
| updated_at | TEXT | 非空 | datetime('now','localtime') | 更新时间 |

索引：`sqlite_autoindex_users_1`、`idx_users_username`（登录名唯一索引）
